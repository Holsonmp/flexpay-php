# Politique de sécurité

## Versions supportées

Avant la première release publique, seule la branche principale candidate est auditée. Après publication, cette section devra lister explicitement les séries supportées.

## Signaler une vulnérabilité

Un canal privé vérifiable n’est pas encore configuré. Cette absence est un blocage avant publication publique. Ne publiez pas de secret, token, identifiant marchand, donnée personnelle ou preuve exploitable dans une issue publique.

Le mainteneur doit activer les avis de sécurité privés du futur dépôt GitHub ou publier un autre canal privé vérifiable, puis mettre ce fichier à jour. Le signalement devrait inclure version/commit, composant, préconditions, impact, reproduction minimale sans paiement réel et proposition de correction si disponible.

N’effectuez aucune transaction réelle, aucun test sur un compte tiers et aucune exfiltration. Il n’existe aucun programme de récompense annoncé, sauf mention ultérieure explicite.
