# Code de conduite

Nous voulons une communauté accueillante, sûre et professionnelle. Chaque participant doit communiquer avec respect, accepter les retours techniques de bonne foi et s’abstenir de harcèlement, discrimination, intimidation, divulgation de données privées ou comportement perturbateur.

Les désaccords portent sur les faits, le code et les risques, jamais sur les personnes. Les mainteneurs peuvent modifier ou retirer un contenu, refuser une contribution ou limiter la participation lorsqu’un comportement nuit à la communauté.

Les incidents doivent être signalés par un canal privé du projet. Ce canal doit être configuré avant publication publique ; jusque-là, ne publiez aucune donnée personnelle dans une issue. Les mainteneurs traiteront les signalements avec discrétion, impartialité et proportionnalité.

Ce code s’applique aux espaces du projet et aux interactions publiques représentant le projet.
